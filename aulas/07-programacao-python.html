ETAPA 1

💻 O que é programação?

Um computador consegue realizar muitas tarefas rapidamente, mas ele precisa receber instruções.

👨‍🍳 Pense em uma receita

Uma receita explica uma sequência de passos:

  1. separe os ingredientes;
  2. misture;
  3. leve ao forno;
  4. espere o tempo necessário.

🤖 Um programa também

Um programa é uma sequência de instruções escritas de uma maneira que o computador consegue interpretar e executar.

Converse com o grupo:
se quiséssemos ensinar um computador a verificar se houve chuva, quais informações ele precisaria receber?
Mini missão sem código: escreva em uma folha três passos que uma pessoa deveria seguir para descobrir, olhando uma tabela, se houve chuva em determinado registro.
ETAPA 2

🗣️ O que é uma linguagem de programação?

Pessoas usam línguas para se comunicar. Na programação, usamos linguagens de programação para escrever instruções para computadores.

🧩 Scratch

Usa blocos visuais para montar instruções.

🐍 Python

Usa textos e possui uma escrita relativamente simples.

🌐 JavaScript

É muito utilizado para criar comportamentos em páginas web.

⚙️ Outras linguagens

C, Java e muitas outras também são usadas para criar programas.

Não existe uma única linguagem “certa”. Linguagens diferentes são usadas em diferentes tipos de problema.
Pense: se existem tantas linguagens, por que escolheremos Python?
